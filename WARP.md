# WARP.md

This repository is the source for Vijay Andem's GitHub profile README.

## Design system

- Direction: clean editorial portfolio for data, BI, and applied AI work.
- Palette: navy, slate, white, and signal blue.
- Layout: mobile-friendly stacked sections with generous whitespace.
- Voice: concise, outcome-led, professional, and specific.
- Assets: theme-aware header SVGs live in `assets/`.

## README structure

1. Theme-aware identity banner and contact links
2. Short professional introduction
3. Current focus
4. Four selected projects
5. Three capability pillars
6. Outcome snapshot
7. Contact call to action

## Maintenance rules

- Keep the selected work list to four projects.
- Describe outcomes and users before listing technologies.
- Avoid typing animations, visitor counters, streaks, badge walls, and decorative contribution animations.
- Use repository-hosted visuals; avoid third-party image dependencies.
- Verify all local image paths and outbound links after an edit.
- Align featured projects with the repositories pinned on the GitHub profile.
